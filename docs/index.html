GAMEPLAY LOOP

一次完整的钓鱼，是五个动作

从抛竿到结算，每一步都有对应的物理表现与状态切换，而不是简单的一段动画。

01

抛竿

给鱼钩一个向右上方的冲量，划出抛物线落水。

02

下沉

入水后重力变小、阻力变大，鱼钩缓缓沉向深处。

03

搜寻

左右微调钩位，用鱼线把钩子「牵」向游动的鱼影。

04

咬钩

碰撞即锁定，鱼的 AI 停止，成为鱼钩的子物体。

05

收线

浮回海平面才结算，鱼获入库并写入存档。

SYSTEMS

六个撑起「能玩」的系统

玩法之外，真正花时间的是跨场景的数据、状态与视角。

🎣

物理抛竿与浮力

冲量抛投 + 入水后切换低重力 / 高阻力，模拟鱼钩在水中的下沉手感。

🧵

动态鱼线

用 LineRenderer 实时连接船底与鱼钩，鱼钩的每一次位移都牵动线形。

🐟

咬钩判定

OnTriggerEnter2D 触发即锁定，单钩单鱼，重复碰撞直接忽略。

💾

跨场景存档

StatusTable 单例 + 可序列化状态对象，海面与水下往返不丢数据、位置精确恢复。

🎥

摄像机重心切换

抛竿前跟随渔夫，抛竿后平滑过渡到鱼钩，出水后再拉回岸上。

🧭

鱼类 AI 与生态

区域内随机巡逻、按游向翻转贴图；水族馆读取背包动态生成已收集的鱼。

TECH

技术上做了什么

  • 状态机驱动的钓鱼流程抛竿 / 下沉 / 收钩 各自独立，切换时机由状态决定，避免动作打架。
  • 父子对象模型实现上下船SetParent 把玩家绑到船上，处理局部坐标与世界坐标的转换。
  • 单例数据中心 StatusTable跨场景持有玩家、船只、鱼获，序列化后写入存档。
  • Canvas 自适应Scale With Screen Size + 锚点布局，不同分辨率下 UI 不走样。
  • UI 动效正弦呼吸的标题与按钮，让主菜单「活着」。
